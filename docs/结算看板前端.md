# 上局结算看板 · 前端说明

适用：木桌前端自 `habitrain_core 2.0.31` 起；动态扇形剖切自 `2.0.33` 起；事件特写与托盘边界截断自 `2.0.34` 起（建议客户端与服务端同版）。后端数据流见交接文档；本文描述前端呈现、木桌显示设置与验收。

## 外观与布局

- 地面方块（`y+0`）：平整的桃花心木拼花桌面、四根木腿、桌边围板与细黄铜镶边；桌下留空，顶面高 1 格（`wathe` 原生纹理，四向朝向，正面朝放置者）。保留原方块 ID，旧存档中的看板直接使用新外形。
- 方块上一层（`y+1`）：正方形的「列车木质镶铜沙盘底座」。底座边长按微缩地图长边加两侧各 0.3 格留边计算（有地图时约 6.85 格，待机或无地图布局时为 4.6 格）。地图保持原比例，最长水平轴归一化到 6.25 格；地图 Z 向更长时自动转 90°，使列车始终横在铭牌前方。
  - 桃花心木人字拼底板、乌木外框 + 内沿黄铜饰条、四角黄铜包角与铆钉、底部微型枕木与双轨托架；`wathe` 纹理缺失时回退原版木纹/金块并染色。
  - 正前方斜置 Art Deco 黄铜铭牌：地图名、模式、翻牌式 `mm:ss/mm:ss` 时钟、当前阶段与进度条；地图仍在补齐时显示 `present/total`。
  - 木桌四角到沙盘底部有暖金色全息承托光束，沿光束流动的小光点。调整显示位置时，光束仍从实际桌面连接到沙盘。
- 裁剪：不走方块实体渲染，按已加载看板索引在 `AFTER_TRANSLUCENT` 对「木桌 + 沙盘 + 荣誉屏」整体做视锥裁剪；包围范围随尺寸、高度、偏移和旋转变化；距木桌 48–64 格渐隐，超过 64 格不提交；24 格外不提交铆钉、名牌、火花等细节；最多同时绘制最近 4 块。

## 每张木桌的显示设置

创造模式下对木桌 **Shift + 右键** 打开设置界面（手持方块或工具也可）。

| 项目 | 范围 | 默认 | 按钮步长 |
| --- | --- | --- | --- |
| 地图长边 | 1–32 格 | 6.25 格 | 0.25 格 |
| 离桌面高度（桌面至地图底部） | 0–16 格 | 0.25 格 | 0.25 格 |
| 左右偏移 / 前后偏移 | 各 -16–16 格 | 0 格 | 0.25 格 |
| 旋转 | -180°–180° | 0° | 15° |

- 可直接输入数值；尺寸保持长宽高比例，沙盘、轨迹、人物与荣誉屏采用同一变换。正偏移沿桌子朝向向右、向前。
- 修改即时预览；保存后服务端同步给观看者，取消或 Esc 撤销未保存的显示修改。恢复默认仍需保存。
- 每张桌子独立存入方块实体 NBT；重进世界、区块重新加载、新一局回放后仍保留。旧存档缺少字段时补默认值。
- 服务端校验创造模式、存活、建造能力、维度、交互距离、已加载区块与目标方块。保存确认由服务端返回。
- 界面内提供本地地图「完整车体 / 动态扇形剖切」切换；该选项沿用本地观看设置，不写入木桌存档。

## 四幕循环（全服按世界时钟同步）

| 幕 | 呈现 |
| --- | --- |
| 发车准备 2.5s | 灯带亮起，金色线框与扫描平面沿长轴掠过，微缩列车逐段显形（着色器裁剪平面），铭牌翻出地图名 |
| 全员推演 16–24s | 立体头像沿样条平滑移动并轻跳，彗星拖尾 + 全程淡轨；击杀/命中/爆炸进入 0.35× 慢镜，地图推近特写并弹出事件简报条 |
| 终局复盘 3.5s | 金色结算波纹扫过整列火车，全部轨迹与节点定格 |
| 荣誉结算 8.5s | 沙盘下沉压暗，Art Deco 荣誉屏展开：胜方标题/副标题/印章、自转头像陈列（职业名、MVP 皇冠）、MVP 战绩、本局时长/总击杀/首杀与终结；结尾收起、地图回缩，无缝进入下一轮 |

- 头像：内层 8×8×8 皮肤头 + 1.125× 外层帽子；在线玩家用实时皮肤，离线玩家异步拉取，未到达前用默认皮肤并自动热刷新。脚下圆环为职业色（死亡变灰，复盘时胜者为金色）。
- 状态：死亡下坠碎裂 → 小墓碑 + 半透明幽灵；复活金色光柱；伪装紫色重影与角标；疯魔暗红气焰；沉睡 `z Z`；停电区间整体压暗并泛红色应急光。
- 节点：击杀猩红脉冲 + 斩击连线 + 悬浮 3D 凶器；弹道白金光束、枪口星芒、未命中火花、掉枪警示；爆炸/下毒/破盾/门锁/技能等各色光环。

## 事件特写与地图截断

- 操作发生时，以事件起点和终点的中点为特写中心，地图、头像、轨迹、武器和空间效果使用同一缩放与位移。托盘、铭牌、事件简报和荣誉屏保持原布局。
- 击杀优先，锁定倍率最高 2.4×；爆炸、命中、反噬、复活、拆弹最高 2.1×；下毒、破盾、埋弹、技能、陷阱、绳索最高 1.8×；投雷、伪装、转职、使用物品和开锁/撬门/封门最高 1.55×。普通开关门、锁门/解锁、停电状态变化不触发特写，避免频繁跳转。
- 远距离操作会自动降低倍率，把操作双方留在同一个镜头中。地图自动转 90° 时，特写焦点也同步转换。
- 推近用 0.3 秒的 Back 曲线：快速冲入、超过锁定倍率、回弹到位；倍率锁定至事件后约 0.8 秒，再用 0.7 秒四次缓入缓出退回全景。峰值略高于锁定倍率。全部按画面播放时间计时，慢动作不拉长特写动画。
- 前 0.3 秒保护当前镜头；随后连续关键事件从当前镜头位置和倍率接续。锁定期间低优先级操作不能抢走高优先级特写。同一时刻的多个事件以优先级最高者为准。
- 进入终局复盘前提前回到全景；本地定格同时定格缩放，恢复后回到同步时间对应的镜头。
- 地图始终裁在固定托盘内沿内侧 0.04 格处。实体、镂空、流体和半透明地图层都在绘制时截断，头像皮肤、文字、武器、轨迹和光效也按同一托盘边界裁切。不同桌子的旋转、显示位置与尺寸均参与变换。原始地图数据保持完整，缩放不触发网格重建。

## 本地观看交互

空手右键看板：

- 右键：本地定格 ↔ 恢复全服同步播放。
- 非创造模式下潜行 + 右键：动态扇形剖切 ↔ 显示完整车体。创造模式下改为打开木桌设置，地图开关在设置界面内。

剖切以当前可见的回放头像为中心，朝观看者一侧展开 **80° 扇形开口**，并在头像附近保留圆角开口以露出正上方的车顶。头像移动、上下楼、死亡留碑或复活时，开口跟随当前回放姿态；离开或尚未出现的头像不产生开口。多个头像各自生成开口，取它们的并集，不再按整局统计高度水平削去整层车顶。每个开口只移除高于对应头像脚部的方块，不向下挖掉该头像的支撑地板；不同楼层的开口重叠时，上层结构也可能位于下层头像的开口内。

扇形方向取观看摄像机朝向的反向，并转换回地图本地坐标；绕桌观看、转头、桌子四向放置、地图自动转 90° 和显示设置的旋转都参与计算。垂直俯视时回退到观看者所在的地图侧面。该效果属于本地观看设置，各客户端可看到朝向自己展开的切口；定格后头像位置保持不动，仍可转头检查不同方向。

地图始终保留完整源数据。回放专用网格预留实体方块的相邻面，绘制时按方块中心判定扇形内外，切口呈贴合方块的阶梯边界，保留下来的方块显示实体表面。头像运动、转头和完整车体开关只更新绘制参数，不重建地图；其他移动场景仍使用原有的面裁剪方式。车窗、流体与第三方特殊模型沿用原有烘焙路径。

## 资源生命周期

- 所有看板共用一份 `SceneMeshSet`；按「地图指纹 + 已到 Section 数」重建，补齐期间合并为最多每 2.5 秒一次，最终完整时立即重建。各看板分别计算观看方向，不因切口变化重新提交地图构建。预留的实体相邻面会增加网格大小，仍受原有网格配额保护。
- 对局结束或采集超时时，仍会展示已采到的地图区段，并保持对局区域的比例。没有采到可用区段时，仍可看轨迹和荣誉结算。
- 断开连接、切换维度/世界、资源重载、新局换图时取消在途构建并 `close()` 旧网格；迟到结果直接关闭；45 秒未渲染任何看板时自动释放显存。

## 验收建议

1. 放置四个朝向的看板，确认待机和回放时沙盘底座俯视均为正方形，地图比例正常，铭牌、沙盘与荣誉屏都正对放置者，木桌碰撞箱与模型一致。
2. 无上局时显示朝向固定、轻微上下浮动的金色线框列车与「暂无上局对局记录 · 等待发车」。
3. 两台客户端同时观看，比对同一时刻的头像位置、慢镜与荣誉屏。
4. 断线重连、F3+T 资源重载、切维度后无报错且画面恢复。
5. 创造模式 Shift + 右键（分别空手、持方块）打开 UI：调尺寸、高度、偏移与旋转，确认地图与人物/轨迹对齐，承托光束保持连接真实桌面。取消应恢复原显示。
6. 两张桌子分别保存不同设置；重新进世界后仍独立保留，另一客户端与稍后加入的客户端看到相同结果。非创造模式不出现设置 UI。
7. 回放头像行走和上下楼时，开口中心及底部跟随头像，身后和扇形外的地图恢复；多个楼层同时有人时检查各处开口及重叠区域。死亡标记继续可见，离开玩家的切口消失。
8. 绕桌四侧、转头和垂直俯视，确认开口向观看者展开；分别调整旋转、偏移和尺寸，地图与头像的切口仍对齐。两台客户端从相反方向观看，应看到不同方向的本地切口。
9. 定格后绕桌转动视角，头像保持定格但切口方向继续变化；切换完整车体后地图恢复，再切回可立即剖切，无需等待地图重建。
10. 击杀、枪械命中、爆炸、技能或使用物品时，确认地图快速推近、过冲回弹、短暂停留后退回；事件双方及地图上的头像/武器/轨迹对齐。连续击杀镜头连续接续，物品操作不抢走击杀特写。
11. 放大后绕托盘四边检查：地图、半透明车窗和轨迹在内沿截断，不越出托盘。调整四向放置、显示旋转、尺寸和偏移后重复检查；远距离击杀应保留双方并自动降低倍率。
12. 特写期间右键定格、等待后恢复，检查缩放与回放时间一致；最后时刻触发击杀后进入终局复盘，应恢复完整全景。
