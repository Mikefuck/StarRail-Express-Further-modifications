# 大厅移动背景

在现有「移动场景」配置页的地图下拉列表选择「大厅（非对局）」。大厅背景独立保存，默认关闭，不继承「默认回退配置」，也不改动各对局地图的背景设置。

1. 手持移动场景配置器，在地图列表选中「大厅（非对局）」。
2. 沿用原有流程选区、设置显示位置、运动参数并保存。
3. 生成场景资产，待诊断通过后点击发布；启用所需背景并保存。
4. 非对局时自动显示大厅背景；进入对局后切换到原有地图背景，实际返回非对局状态后恢复大厅背景。保存大厅设置后约一秒内更新。

现有的线性/环绕运动、多个背景、车外音、微震和预览等配置项均保持原有含义。大厅也沿用原有的最多五个背景与 OP2 配置器权限。加入服务器和换维度时由服务器同步当前背景。

JSON 仍使用现有 `sceneMotion` 结构：大厅主背景保存在 `profiles.__lobby__`，附加背景保存在 `backgrounds.__lobby__`，不更改原有 schema 和其他地图键。大厅只在主背景 profile 的 `dimension` 对应维度、且不在对局时自动启用；未配置时不产生大厅运行状态。
