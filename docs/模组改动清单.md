## 1. 总览

| 类别 | 概要 |
|------|------|
| **框架** | GameMode / Task 可扩展 API；配置 JSON + 网络同步 |
| **模式** | SRE 谋杀/修机代理、停电模式、SRE 原版其它模式投票桥 |
| **任务** | 内置任务 + 停电任务池；Mixin 接管 SRE 任务生成 |
| **职业** | 投稿职业 5 + 七宗罪 7；CCA 组件 |
| **修饰符** | 七美德 6 新建 + 关联上游「慷慨」 |
| **投票** | 通用选项投票；模式→地图两阶段；地图池日轮换 |
| **槟榔** | 强制成瘾；任务/进食限制集成 |
| **客户端** | 透视色/方块高亮、停电 HUD、配置 GUI、多项 SRE UI 修复 |
| **Mixin** | 服务端 ~28 + 客户端 ~15（含 accessor） |

## 2. 公开 API 与框架

**包:** `com.habitrain.core.api`（详见 [API参考手册](./API参考手册.md)）

| 能力 | 说明 |
|------|------|
| `TaskRegistry` / `TaskDefinition` / `TaskInstance` / `TaskCategory` | DLC 注册自定义任务、生命周期回调、限时、TimeImpact |

| `GameStateProvider` / `SREGameLauncher` | 核心内部解耦 SRE 的注入点 |

**内部引擎（非稳定 API，但属本 mod 功能）:**

| 模块 | 职责 |
|------|------|
| `task/TaskManager` | 任务分配、配置权重、平衡 |
| `task/TaskBalancer` | DLC 任务概率自动平衡 |
| `task/TaskPoolBuilder` | 按模式构建任务池缓存 |
| `task/GameLifecycleHandler` | 对局结束清理 handler 状态 |
| `task/SlownessReapplyManager` | 缓慢效果重施（对抗 betel 清效果等） |

## 4. 任务系统

### 4.1 对 SRE 的接管

| 改动 | 机制 | 说明 |
|------|------|------|
| 任务生成接管 | `GenerateTaskMixin` | 统一权重池：原版代理任务 + 自定义任务；支持配置过滤、平衡、停电专用池 |
| 任务 tick / 回收 | `SREPlayerTaskComponentMixin` | 自定义任务 tick、完成、替换时 `ItemReclaimHelper` |
| 地图扫描扩展 | `MapScannerMixin` | 扫描自定义任务方块、停电常驻高亮（电话等）、盘子吃喝 typeId |
| 角色任务奖励/行为 | `RoleMethodDispatcherMixin` | 与配置/自定义任务/默剧等联动 |
| 并列任务字幕抑制 | `SuppressParallelTaskSubtitleMixin` | 屏蔽「并列任务」及重复 task.* 顶栏字幕 |
| Outside 瞬间完成防护 | `OutsideTaskInstantCompleteMixin` | 防止 OutsideTask timer 异常过短 |
| 停电任务间隔 | `BlackoutTaskIntervalMixin` | 取消 SRE 对 blackout 的固定冷却特例，走动态冷却 |
| 锻炼目标扩展 | `ExerciseDeadCoralMixin` + `ExerciseMapScannerMixin` | 锻炼任务/高亮接受枯萎珊瑚（全模式） |

### 4.2 内置非停电任务（`BuiltinTaskRegistrar` / 槟榔）

| fullId | 显示名 | 分类倾向 |
|--------|--------|----------|
| `habitrain_core:pet_cat` | 摸猫猫 | 谋杀等 |
| `habitrain_core:search_backpack` | 翻找背包 | 含道具发放/回收 |
| `habitrain_core:look_my_eyes` | LOOK MY EYES | — |
| `habitrain_core:betel_quest` | 槟榔相关任务 | 槟榔系统 |

另：SRE 原版任务通过 `SREGameModeBase` 静态路径代理注册进本池（受配置开关控制）。

### 4.3 小游戏 (Minigame) 配置介入

| 改动 | Mixin | 说明 |
|------|-------|------|
| 地图禁用小游戏重选 | `MinigameTaskAssignmentMixin` | 当前地图禁用则换候选或清空 |
| 小游戏奖励覆盖 | `MinigameRewardMixin` | 按配置改金币/情绪等奖励 |

| 功能 | 说明 |
|------|------|
| 好人/坏人任务池 | `BLACKOUT_GOOD` / `BLACKOUT_BAD` 分类 |
| 计时 / 维护 / 瞬时停电 | `BlackoutTimerSystem` 等 + S2C 同步 |
| 胜负判定 | `BlackoutVictoryChecker` |
| 角色管理 | `BlackoutRoleManager`（阵营 GOOD/BAD 等） |

| 开局报幕 | `BlackoutAnnouncePayload` + 欢迎渲染 |
| 死亡处理 | `BlackoutDeathHandler` |
| 每局仅一次任务 | 如 `furnace_explosion` |

## 12. 网络同步

`NetworkRegistrar` 注册 **25** 类 payload（方向以类/接收器为准）：

| Payload | 用途方向（概要） |
|---------|------------------|
| `TaskConfigPayload` | S2C 任务配置 |
| `ActiveTaskPayload` | S2C 活跃任务（透视） |
| `ConfigUpdatePayload` | C2S OP 配置更新 |
| `FullConfigSyncPayload` | S2C 全量配置 |
| `ShaderConfigPayload` | S2C 光影白名单 |
| `ShaderInfoPayload` | C2S 客户端光影包名 |
| `CustomTaskBlockPayload` | S2C 自定义任务方块缓存 |
| `BlackoutTimerPayload` | S2C 停电计时 |
| `BlackoutAnnouncePayload` | S2C 开局报幕 |
| `BlackoutSheriffVotePayload` / `Cast` | S2C 状态 / C2S 投票 |
| `BlackoutPhoneOpenPayload` | S2C 开电话 UI |
| `BlackoutHirePolicePayload` / `HireResult` | C2S 雇警 / S2C 结果 |
| `BlackoutVotePayload` / `VoteCast` | S2C 投票 UI / C2S 投票 |
| `BlackoutTaskShopOpen` / `Buy` / `Result` | 任务商店 |
| `OptionVotePayload` / `OptionVoteCastPayload` | 通用选项投票 |
| `MapPoolSkipPayload` | C2S 跳过地图池 |
| `GreedTradeSelect` / `Prompt` / `Action` | 贪婪匿名交易 |

另：`VotePurpose` 枚举区分投票用途。

**客户端上报:** `ShaderMonitor` 轮询 Iris（反射，无编译依赖）→ 服务端白名单踢出逻辑（生命周期/配置）。
