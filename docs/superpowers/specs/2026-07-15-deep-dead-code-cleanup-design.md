# HabiTrain Core 深度死代码清理设计

## 目标

在不改变当前游戏设计、角色设定、数值、胜利条件、网络协议和公开 API 的前提下，删除已经没有有效入口、与当前设计冲突或只剩空壳的实现。

## 不变量

- 七宗罪、七美德及已有自定义角色的机制和数值保持不变。
- 停电模式继续使用 SRE 原版职业商店；独立的停电任务商店保持不变。
- 贪婪继续使用专用匿名交易界面、双确认和服务端原子结算；命令确认入口保留为兼容回退。
- `com.habitrain.core.api` 下的公开 API 不因“仓库内无调用者”而删除。
- 不清理用户的未提交功能文件、依赖 JAR、Claude/Codex 工具目录或其他 Git worktree。

## 清理范围

1. 删除未注册或已被替代的 Mixin：未注册的双节棍冷却实现，以及三个已注册但注入体为空的客户端/商店 Mixin；同步移除 Mixin 配置项。
2. 删除与“始终使用原版职业商店”设定冲突且无调用入口的旧停电角色商店覆盖闭环，包括目录、定义、ShopEntry、服务和空初始化/重置调用；保留 `game.blackout.shop` 下当前任务商店。
3. 删除贪婪交易中已被专用 GUI 替代的聊天按钮生成方法、无调用的价格快捷方法/交易有效性空判断，以及对应废弃翻译；保留 C2S 和命令兼容入口。
4. 删除经仓库与已知配套项目调用扫描确认无引用的内部辅助方法、别名、字段和占位方法。
5. 更新仍描述 MVP/聊天流程的注释，使其与现有 GUI 流程一致，不改变执行逻辑。

## 验证

- 删除前后比较 Mixin 类与两个 Mixin JSON 的注册关系。
- 对所有删除符号和资源键执行全仓库复扫。
- 使用 Java 21 执行 `./gradlew build`。
- 核验 remap 后的 `habitrain_core-2.0.0.jar` 已复制到 `D:\Backup\mc mod\临时`。
