## 已落实的用户决定

1. 旋转/环绕场景的面明暗随当前世界方向改变。采用移动场景专用地形 shader，使用变换后的法线和相机相对雾距离；保存的光照与非方向颜色仍来自快照。
2. 仅限制原版警长（VIGILANTE）误得的本能；自定义警察阵营角色遵循自身定义，显式授予本能仍放行。
3. 与光影冲突时优先保证方向明暗，移动场景使用自身 shader。该实现选择已经落实，Iris 实机兼容尚无证据。

## 主要修复

- 流体跨 section 坐标恢复，包含负坐标；完整四边形校验、配额先检查、恢复各面的法线。
- 保留全场景不透明层先提交，透明四边形及适配器三角形按每实例的局部相机重新排序；索引缓冲计入显存估算。
- 资源重载先使旧任务失效，释放 current/prepared/additional 网格，重建仍在使用的资产；异步下载和烘焙都有世代/请求身份检查，取消真正移除调度任务。
- 预览 PNG 先验证长度与尺寸，再在有界后台队列解码；纹理注册、关闭留在客户端线程。每个条目独立延迟释放，断线和晚到回调不会重新填回旧缓存。
- 嵌套 FBO 分别保存 draw/read 目标及精确 viewport；直接绘制用统一状态保护恢复深度/混合/裁面/颜色。GuiGeo 避免异常后占用全局 Tesselator。
- TicketShaders 将编译错误交回 Minecraft 的资源包回滚流程，成功整批编译后才替换程序引用。
- null/图标按钮身份、disabled、Tab 离开和动画点击拦截得到修正；放置工具取消、弹窗 token 消费、角色行偏移、缓存的胜利文本与多余深度缓冲得到处理。
- 新增断线清理的一次性交接入口：由排队回调或客户端更新执行同一待办，新连接使旧待办失效。实机复现的旧预览引用残留已纳入回归。
- 真实窄窗口、GUI 缩放为 1 时发现文字缩小循环可能把 2.5 再取整为 3，持续不前进。开局/结算转场共享至少减小一个屏幕像素的计算，避免卡死。

## 验证方法与证据

所有 Gradle 命令通过本项目 wrapper，带 `--no-daemon`。`verification/Invoke-S6Gradle.ps1` 将运行目录和 Gradle 缓存定位在项目内，跟踪本次进程及 Java 子进程，在 finally 中等待退出并保留原始构建结果。

最终构建与运行汇总、JAR 摘要、测试计数和进程清理结果由 `.verification/s6-20261107/final-verification.json` 记录。生产客户端使用实际 remap JAR，通过 KnotClient 的生产命名空间启动；额外验证模组仅位于隔离目录，不打进交付包。

验证入口：

```powershell
.\verification\Invoke-S6Gradle.ps1 -Name <唯一运行名> -GradleArguments @(
    'build', 's6ProductionClient', '--offline',
    '-I', '.verification/s0-20261106/offline-cache.init.gradle',
    '-I', '.verification/s6-20261107/production.init.gradle'
)
```

`Name` 只能使用小写字母、数字和连字符，替换示例中的占位符后执行。辅助脚本会追加 `--no-daemon`；已有同名日志不会覆盖。H: 临时盘符必须空闲。

GPU 环境：NVIDIA GeForce RTX 4060 Laptop GPU，OpenGL 3.2.0 NVIDIA 621.01；原版渲染管线，包含上游 SRE 和项目固定依赖。

## 失败记录和诊断边界

早期构建/验证失败均保留日志和进程记录，没有用后续成功覆盖：包括编译括号错误、测试期望与关闭时机不符、验证模组 remap classpath、预览时间宽限的错误测试方式、坏包回滚原 Future 不结束、验证程序漏调用原版断开世界步骤等。最终报告只采信最后一次成功运行结果。

坏包回滚时最初返回的 reload Future 未结束，但实际坏包已移除、后继重载和绘制已恢复。因此验收依据是资源包状态、活动网格替换与实际 shader 像素，未把原 Future 的未结束误判为恢复失败。

生产运行日志含主动注入的 shader 编译 ERROR，以及离线认证连接、上游缺失模型/标签、无抽奖池配置等既有信息；“日志零 ERROR”不是本轮通过条件。
