## 确认后的补充修复与验证

两项 API 决策已登记；其余 9 项仍按各自验证边界处理。此次补充修改了 5 个生产类，并新增 19 个 JUnit 用例：

- 重连任务同步：读取对局状态失败时跳过本次任务同步，不将失败伪造成“未开局”，保留服务端任务。实际专用服故障注入验证普通异常、链接错误、正常运行及确认为非运行状态四种情况；确认非运行时仍清除旧任务并发清空包。
- 致命错误传播：公开开始/结束事件、内部结算事件及生命周期隔离边界保留对普通异常/断言失败的隔离，但向上传播 VM、线程和链接错误。公开 API 直接使用 JDK 错误类型，继续通过接口层依赖检查。
- 退出清理：尽力执行余下必要清理、保留所有失败诊断，最后传播首个致命错误；覆盖嵌套清理与多个失败。

累计相对 S8 开始快照改变 72 个源码/资源/测试文件。最新异常文本清单为 437 个 Throwable 捕获、151 个空或仅含注释的 catch，清单不等于语义审查完成。首轮补充构建被 API 层依赖检查拒绝，修正后重新完整构建通过，失败日志及其进程清理记录均保留。

结算必要数据读取失败后的正式通知策略仍需 Mike 决定，详见 `S8结算异常处理待确认.md`；该工作归入 X-CUT-09 的部分完成项，不是上述两项 API 决策的延伸确认。
