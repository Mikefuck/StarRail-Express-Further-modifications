# 停电模式移除

## 行为变化

- 移除 Core 自定义停电模式及 `/habi_api blackout` 入口，不再出现在模式注册表和模式投票中。
- 删除该模式的电力倒计时、阵营管理、胜利判定、断线宽限、电话雇警、放逐投票、任务商店、专属任务、HUD、网络消息和电话音效。
- 清理旧配置中的停电模式、停电专属任务、投票项、临时电源价格和任务商店价格。保留其他模式及其他模组的配置条目。
- 槟榔任务及配套交互已移除，Core 不再依赖槟榔模组。

## 共用功能

- 普通 SRE 拉闸/关灯物品、通用冷却和黑暗时长增强继续保留。
- 进食、喝水任务继续用于普通模式，不再附带停电计时效果；旧吃喝任务配置迁移继续保留。
- 投票快捷键迁移为 `client.VoteKeyHandler`，模式/地图投票与开局加载页继续使用原有按键。
- `ForcedReadyJoinGate` 迁移到 `game.sre`，保留启动期间已确认参与者的加入保护。
- 改职后的通知、统计、回放和同步迁移到 `SreRoleAssignmentEffects`；胜利钩子兼容层迁移到 `role.override.RoleOverrideWinHook`。
- 谋杀、修机、维修人员功能、七宗罪、普通任务及其他已存在的工作区修改予以保留。

## 兼容边界

`GameModeIds.BLACKOUT` 及历史阵营映射、旧吃喝常量、v1 `BlackoutWinCheckContext` 签名和 `TaskDefinition.TimeImpact` 元数据仍保留，供已有扩展或历史数据使用。这些兼容声明不注册模式、不启动停电计时，也不再改变 Core 任务权重。

依赖已删除 `game.blackout` 实现包或停电专属网络包的第三方源码需要迁移。当前抽奖补齐源码中查到一条未使用的 `BlackoutRoleManager` import，没有查到调用；本次未修改抽奖补齐项目。

客户端和服务器应一起替换本次 Core JAR 并重启；任务配置网络格式已同步移除商店价格字段。

## 验证范围

执行 Gradle 构建与测试，并检查交付 JAR 中已无停电模式实现和专属网络包、全部 Mixin 配置均能对应到实际类。新增回归覆盖旧配置清理、配置同步、共用入口保留以及 Mixin 注册完整性。

未启动 Minecraft 客户端或专用服务器进行实机联机验收。仍需实际确认模式列表、普通模式开局、投票按键、任务完成及七宗罪改职/结算行为。
