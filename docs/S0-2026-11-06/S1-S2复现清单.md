# S1 / S2 首批复现与回归清单

2026-11-06。这里只准备验证入口和可操作步骤，不把旧报告或一次全量测试通过当成缺陷已关闭。85 个主闭环条目全部登记；跨阶段安全子项开始实施时还需从完整台账追加。

权限矩阵：普通玩家、OP2 无/有菜单授权、OP4 无/有菜单授权、服务端控制台、命令方块、控制台/玩家经 execute as 转换的来源。授权策略冲突交由用户确认；所有攻击样本仅在隔离目录或内存缓冲区执行。

## R01 权限与拒绝

在隔离服用普通玩家、OP2/OP4 各有/无菜单授权、控制台与 execute 转换来源分别请求配置读写、角色配置和管理场景。拒绝应无配置快照、无文件改动和无广播。先记录现有矩阵；有策略冲突先讨论。

已有或计划入口：ConfigUpdateAccessPolicyTest / ConfigUpdateAdmitPolicyTest / ConfigPatchPayloadTest；真实来源与网络拒绝待 S1。

## R02 包长度、嵌套与编解码预算

在内存 ByteBuf 构造负数、上限、上限+1 和只给包头的截断载荷；配置路径逐层加深，场景制造大量空 Section。检查拒绝前无大分配，编码可解码，合法最大样本仍通过。

已有或计划入口：ConfigPatchPayloadTest / SceneAssetChunkProtocolTest / SceneCodecTest；实际峰值预算待 S1。

## R03 光影握手与单调时间

可控时钟测试初次静默、空名称、错误 revision、小包重复上报、重检超时和合法更新。所有拒绝有终态；自报不能证明未作弊。

已有或计划入口：C2SRateLimiterTest；完整握手状态机待 S1。

## R04 路径与暂存所有权

只在临时目录测试 ../、绝对路径、64 位非十六进制键、Windows 设备名；A 管理员创建暂存，B 普通玩家/管理员发错 UUID。检查外部哨兵文件未变、A 会话未被删除。

已有或计划入口：SceneAssetStagingStoreTest / ScenePartialStoreTest；Windows 和真实服务端授权待 S1。

## R05 捕获与后台队列

用可暂停的压缩任务占满工作队列后重复发起捕获，再取消及关服；计数、排队和内存必须有界，旧任务不得发布。

已有或计划入口：SceneCaptureAccountingTest / CaptureTicketWindowTest；完整后台队列与世界访问待 S1/S2。

## R06 隐私同步与本能开关

两名存活玩家、拥有者、授权旁观者与复活观察者同场，抓取 CCA/状态包；私有场景尝试清单及分片下载，检查种子和方块实体敏感字段。关闭本能时，自定义规则不应意外授予常驻透视。

已有或计划入口：RoleSnapshotPayloadSplitTest / LustRestrictionSyncTest；真实 CCA 和多客户端待 S1。

## R07 服务器目标复核

向不同维度、隔墙、越距、未加载区块、维修员/大厅玩家发技能目标。应按服务端声明拒绝，并比较区块数及磁盘目录，确保没有意外加载。

已有或计划入口：ApiRuntimeRegressionTest；真实世界和区块计数待 S1。

## R08 双端与依赖组合

完整生产组合与移除真正可选 TACZ 的组合分别启动；测试公共客户端门面在专用端的加载。移除 voicechat 的完整安装应在 Fabric 依赖解析处被 SRE 硬依赖拒绝，不能作为受支持组合。

已有或计划入口：SceneDedicatedServerClassLoadingTest / production-minimal/full；真实启动待 S1。

## R09 必要 Mixin 与故障策略

以重映射 JAR 启动并导出转换后的类，触发击杀、休息区攻击/换模式、维修初始化/重置/选角各入口，再运行 verifyProductionMixins。无导出、缺类、缺处理器都必须失败。另注入守卫内部异常检查是否错误放行。

已有或计划入口：SafetyMixinInjectionPointTest / RoleFixMixinCompatibilityTest；生产命中和故障行为待 S1。

## R10 扩展生命周期能力

真实外部附属模组在入口回调中尝试 freeze/clear/bind/dispatch；注册阶段正常操作仍可用，扩展不能意外继承内部生命周期权限。同进程 Java 模组不构成沙箱。

已有或计划入口：CoreLifecycleScopeTest / CoreSpiWiringTest；真实附属模组待 S1/S3。

## R11 线程和客户端编辑归属

客户端正在编辑时从网络线程断线、被弹窗替换、退出 A 再进 B；并发读取配置/语音快照。检查主线程收尾、编辑标记复位和服务端权威对象无跨线程访问。

已有或计划入口：ConfigSyncReloadTest / LifecycleCleanupTest；真实线程与音频回调待 S2。

## R12 持久化与失败反馈

临时目录放坏 UTF-8/截断主文件和好备份，另将 .bak 设为目录或注入写失败；校验至少一个好版本可读、坏主文件不覆盖好备份，命令/客户端不得报保存成功。

已有或计划入口：AtomicJsonFilesTest / ConfigStoreBackupRecoveryTest / ConfigSaveSideEffectsTest；实际权限/磁盘故障待 S2。

## R13 连接世代、停机与晚到任务

用闩锁挂起捕获/传输/缓存 Future，断线重连或关服/重开 B 后才释放；旧任务不得写新会话，线程池不复活，所有请求有终态。

已有或计划入口：SceneStagingSessionTest / SceneBuildSchedulerTest / ScenePreloadAcknowledgementTest；跨服务器实例待 S2。

## R14 状态清理与引用

建立玩家/世界槽、LAST_VIEW、静态任务引用后复活、退出和连续两局；注入未知 NBT 版本及晚到客户端包，按状态归属检查差集与保留策略。

已有或计划入口：RoleStatePersistenceTest / RoleStateAtomicSyncTest / LifecycleCleanupTest；真实换档待 S2。

## R15 配置迁移与身份归属

同名不同 UUID、同 UUID 改名、单字段越界但其他字段合法，加载历史配置并保存失败；不得转移权限、丢弃合法内容或删除错误旧 UUID。

已有或计划入口：MenuGateServiceTest / ConfigRepairRegressionTest；命令端回滚与迁移取舍待 S2。

## R16 未装配桥接默认行为

在独立测试进程分别测试未装配、已装配和抛错桥接；休息态与门控默认值遵守公开契约，null server 的重载不得跳过真实归属。

已有或计划入口：CoreSpiWiringTest / MenuGateServiceTest；相关契约主闭环待 S1。

## R17 语言与公开状态调用

扫描全部打包语言表和 Java 直接字面量翻译调用；对上游覆盖键按实际调用参数复核，占位符在游戏中应显示正常。

已有或计划入口：SceneLanguageFormatTest；上游生产 UI 的实际显示待 S1/S6。
