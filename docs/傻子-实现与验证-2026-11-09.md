# 傻子（Idiot / Fool）实现与验证

日期：2026-11-09。项目：`habitrain_core`，Fabric / Minecraft 1.21.1。交付版本：2.0.29。

## 最终机制

| 项目 | 实现 |
| --- | --- |
| 角色定位 | 平民阵营，与平民共同获胜；角色 ID 为 `habitrain_core:idiot`，默认每局最多分配 1 名，接入现有角色扩展 v2 |
| 使用方式 | 开局配发专属鸡蛋，主手右键无限投掷，数量保持 1；服务端冷却 10 tick（正常 20 TPS 下为 0.5 秒） |
| 绑定 | 绑定本人和本局；拦截丢弃、容器点击、快捷转移、数字键交换、收纳袋、嫉妒掠夺与小偷偷取；禁止装入原版容器物品 |
| 普通命中 | 只干扰其他存活的对局玩家，不造成伤害；轻微水平击退、20 tick 的 15% 减速及短暂蛋液边缘提示；反馈不区分阵营 |
| 连控保护 | 每个受击目标共享 60 tick 保护期，多名傻子不能轮流连续减速同一目标 |
| 孵化 | 每次有效破碎独立 2% 概率孵出一只小鸡；使用独立投掷物，不进入原版鸡蛋伤害、孵化和四鸡逻辑 |
| 首鸡保底 | 本局首次孵鸡最多 60 次有效破碎；提前自然孵出也会消耗首次保底，后续恢复独立 2%；未命中而超时、被清理的蛋不计数 |
| 保底生命周期 | 同一玩家本局内死亡、失去角色、断线重连都不重置；新回合统一重置 |
| 孵鸡奖励 | 200 tick 的等效速度 II（+40%）；重复触发刷新到 10 秒，不累计时长、不补充冲刺额度；兼容原版速度药水，避免与原版速度 II 或更强效果叠加 |
| 小鸡行为 | 保持幼年、快速乱窜，偶尔向 6 格内有视线的非隐身玩家移动；趣味名字只在近距离且有视线时显示 |
| 小鸡保护 | 不接受伤害、不参与推挤、不作为可选取攻击目标、不繁殖、不产蛋、不产生死亡掉落，也不保存到世界文件 |
| 自然清理 | 鸡蛋最多存在 80 tick（4 秒），小鸡最多存在 300 tick（15 秒）；小鸡消失时有轻微烟雾与鸡蛋音效 |
| 数量上限 | 在场鸡蛋每人 8 枚、全场 32 枚；小鸡每人 3 只、全场 12 只；孵鸡达到小鸡上限时先移除最旧的小鸡，再生成本次小鸡和奖励 |
| 角色清理 | 死亡、断线、失去角色、离开所在维度等失效条件会移除相应临时实体；回合生命周期和服务端停止时统一清理 |

所有 tick 时长均随服务器逻辑时间推进；低 TPS 下对应的实际秒数会变长。

## 视听表现

- 飞行时有少量黄色尘埃与羽毛物品粒子。
- 命中时有黄白飞溅、蛋壳粒子、清脆破裂声及轻微黏液声。
- 命中玩家只在画面边缘显示半透明蛋液，不遮挡准星，不强制转动或抖动画面。
- 孵鸡时有彩色尘埃、羽毛、金星与爱心；周围玩家听见高音鸡叫。
- 投掷者收到独立的大号“咯咯哒！出鸡啦！”提示、10 秒加速提示及分段经验球音效；右下角显示加速剩余时间或首次保底剩余枚数。
- 加速期间脚下有轻量羽毛和疾风粒子。
- 配置中心新增“傻子特效”入口，也可使用客户端命令 `/idiotvisual`；蛋液边缘提示、大号中奖提示、粒子密度均为本机选项，保存到 `config/habitrain_core-client.json`，不改变服务端技能效果。
- 复用 Minecraft 原版鸡蛋、羽毛、小鸡和音效资源，新增中英文翻译。

## 主要实现入口

- `src/main/java/com/habitrain/core/game/sre/role/idiot/`：物品、投掷物、小鸡、服务端规则和回合状态。
- `src/main/java/com/habitrain/core/client/idiot/`：粒子、提示、音效触发与本地设置页。
- `src/main/java/com/habitrain/core/network/IdiotEffectPayload.java`：服务端到客户端的特效与私有状态同步；含消息类型、坐标及计数边界校验，不新增客户端投掷请求包。
- `IdiotEggDropMixin`、`IdiotEggContainerMixin`、`IdiotEggTheftMixin`：补足绑定物品的丢弃、容器和上游偷取拦截。
- 现有角色注册、钩子、客户端视觉配置、贪婪收纳与嫉妒掠夺入口：接入新角色并处理交互边界。

## 验证与证据

1. 完整构建使用项目 wrapper，始终附带 `--no-daemon`；最终命令为 `gradlew.bat build idiotProductionServer --no-daemon --offline -I .verification/idiot/production.init.gradle`。
2. 新增 8 项单元测试，覆盖 2% 边界、60 枚首次保底、自然孵鸡后不再保底、生成失败时保底保留、刷新而不累计加速、速度药水补偿，以及特效消息往返和非法数据拒绝。
3. 使用重映射后的正式 JAR 启动独立专用服务端，检查角色注册、归属校验、物品防转移、防偷取、真实 tick 冷却、投掷物上限、孵鸡、无伤命中、共享命中保护、外部药水兼容、临时实体时限与回合重置。
4. 使用正式客户端检查物品和实体渲染、孵鸡粒子、边缘提示、计时 UI、音效触发、本地选项保存，以及配置中心入口；人工查看中文截图，并修正设置页标题被背景覆盖的问题。
5. Java 进程跟踪记录放在各次命令的 `*.result.json` 中。最终结果及交付 JAR 的哈希记录在文末。

主要证据位于项目 `.verification/idiot/`：

- `server/runtime/idiot-result.json`
- `client-3.log`、`client-3.result.json`、`client/runtime/idiot-result.json`
