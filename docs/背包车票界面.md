# 背包车票界面

打开上游 `LimitedInventoryScreen` 时，客户端会显示蓝色乘车凭证：旅客模型、参与/旁观打孔、随身行李栏、翻牌时钟和检票副券。上下邮票、两张衬纸、车票与背景均不再随鼠标移动而错开；两侧的线框机车与星穹仪逐段组装。邮票在悬停、键盘选中或点击时给予抽出、高亮、图标旋转与盖戳反馈。

候车时，原便捷菜单化为插在票后的邮票。每排普通选项在左、OP 选项在右，同类选项保留原有顺序。票面不再播放白色扫光。悬停会抽出邮票，点击盖戳后执行原菜单动作。对局中，快捷栏保留原坐标，菜单变成右下角可展开的邮票册，避免移动职业控件和商店。

## 操作

- “简洁模式：开启 / 关闭”是一枚与菜单一致的齿孔邮票，使用齿轮图标和灰蓝油墨，排在候车页下排普通选项一侧，对局中也加入邮票册；菜单过多时随其他邮票分页。点击盖戳后切换，也可按 `F6`，或用 `Tab` / `Shift+Tab` 选中后按确认键切换。切换保留当前邮票页与键盘选择，并保存在本机 `config/habitrain_core-client.json` 的 `lightweightInventory` 项，不同步给服务器。
- 简洁模式保留原有车票布局、全部菜单、参与切换和物品操作；关闭星空、背景线框、衬纸、光晕及全身模型，改用静态头像、图标和简化纸边，时钟直接更新数字。
- 鼠标悬停或点击邮票；过长的名称可在提示中查看。
- `Tab` / `Shift+Tab` 选择，方向键调整，`Enter` / 空格打开。
- 候车页在车票范围内滚轮翻页；对局中在邮票册上滚轮翻页。也可点击页码两侧箭头，或使用 `PageUp` / `PageDown`。
- 上下邮票完全抽出的位置与底部提示均参与窗口适配；物品显示和操作共用本帧坐标。
- 线框运动随原版“画面效果”强度减弱，设为零时关闭背景运动；鼠标视差已移除。

## 新增选项

继续通过上游 `GameMenuEntries.entries_hub(...)`（候车）和 `GameMenuEntries.register(...)`（对局）添加菜单。界面会同步上游按钮列表，自动为新增条目生成邮票，并保留原按钮的点击动作。候车邮票每页最多两排；对局邮票每页最多两列，超出后分页。

图标和邮票颜色按翻译键选择，未知条目使用水晶图标。若要为新条目指定图标，在 `TicketInventoryLayer.iconFor(...)` 中添加映射即可，无须修改布局。地图轮换和任务点设置始终显示 OP 标记，仅 OP2 可打开；执行延迟动作前会再次确认权限，回退到上游控件时同样受限。

切换对局状态、关闭邮票册、重建页面或翻页会取消未完成的延迟动作。界面渲染失败时恢复上游控件，并记录错误日志。

## 验证

邮票只绘制露在车票外的部分，阴影、图标、邮戳和文字共用裁剪范围；解除裁剪前先提交缓冲文字，防止藏在票后的黑色阴影或文字穿透票面。精致模式的邮票纸面、票面防伪纹采用局部坐标显卡缓存；简洁模式的静态图标也只生成一次。缓存归当前屏幕所有，翻页、布局或模式改变、关闭背包时释放，返回子页面后按需重建。画面效果为零时，背景线框投影也复用静态缓存。时钟静止时合并绘制，日期与时间按日/分钟更新；槽位坐标每帧计算一次并复用。

```powershell
.\gradlew.bat build --no-daemon
```

`TicketUiGeometryTest` 覆盖小窗口适配、邮票旋转/放大后的命中范围，以及大量菜单条目的分页边界。视觉验证需同时检查候车页、对局邮票册、GUI 缩放、物品拿取和子页面返回。
