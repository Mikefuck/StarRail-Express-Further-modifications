## 生命周期

| 状态/资源 | 拥有者 | 创建/更新 | 断线/跨维度 | 局终 | 停服/退出存档 |
| --- | --- | --- | --- | --- | --- |
| SingleMatchGate | 一次服务器启动 | SERVER_STARTED 重置实例 UUID；投票/加载/开局占用局标识 | 跨维度不能创建第二局；断线不结束对局 | 结算及清理后释放 | 停止接单后重置 |
| ForcedReadyJoinGate | 本局准备期 | 开局前快照 | STARTING/INITIATING 允许名单内玩家重连 | ACTIVE、中止均清空 | 清空 |
| SceneTransferService | 服务器启动世代+玩家代数 | 请求提交时分配代数并固定源文件 | 真实断线清授权/窗口；下一请求新代数；跨维度保留授权并复验可见性 | 带宽阶段随对局更新 | 关闭接单、代数失效、取消定时器/IO、有限等待 |
| SceneCaptureService | 服务器世代+编辑器会话 | 服务端逐 tick 捕获，后台纯数据编码 | 所属管理员断线取消；晚进度/晚暂存检查会话 | 不替代场景编辑器本身语义 | 关闭接单、取消任务、释放票、取消并等待后台 |
| SceneStagingService | 服务世代+管理员/编辑器 | 暂存/发布与停服失效互斥 | 会话轮换或离线拒绝旧结果 | 按暂存确认/超时管理 | 禁止新发布、失效会话、关闭发布线程、清暂存 |
| SceneInstanceService | 服务端场景运行时 | 服务端实例 API | 退服移除追踪；维度按当前快照筛选 | 按实例配置 | shutdown 清引用 |
| SceneAssetStore/DeltaStore | 当前存档 | bindWorld | 不因普通玩家断线解绑 | 已发布资产保留 | 生产者停止后 bindWorld(null) |
| VoicePermissionSnapshot | 服务端 tick | 一次发布不可变参与者/政策快照 | 退服移除；新 tick 更新维度/位置 | 政策/角色由新快照反映 | 停止发布并清空 |
| CustomTaskBlockCache | 服务端扫描会话 | MapScanner/任务生命周期 | 客户端不能修改此实例 | 按服务端任务清理 | 既有清理入口 |
| ClientTaskBlockCache | 客户端连接 | INIT 清空；S2C 装载 | DISCONNECT 清空 | 客户端局终清理 | 客户端生命周期 |
| ClientConnectionSession | 一个 play listener | INIT 发布身份 | DISCONNECT 仅清自己的身份；旧 callback 不触达新连接 | 不因局终替换连接 | 断开连接 |
| 客户端地图/配置/角色/场景镜像 | 客户端连接/渲染线程 | INIT 重置；S2C 校验连接后更新 | DISCONNECT 主线程清理；JOIN 保留早到快照 | 按局内/连接状态区分 | 客户端停止钩子刷盘/释放 |
| ROLE_STATE ROUND/NONE | 服务内存、玩家/对局 | RoleStateService | 同局重连按状态语义；不落 playerdata | 清全局内存槽，覆盖离线 UUID | 清 transient/round |
| ROLE_STATE WORLD/PERMANENT | 玩家或世界 CCA | 编码持久槽 | 跟随拥有者，未知 NBT 保留 | 不盲目清永久状态 | WORLD 的退出语义待 Mike 确认 |
| RoleChange timelines | 本局角色历史 | 角色变更 | 保留同局离线历史，不作为下一局历史 | Clearable registry 清理 | 清会话 |
| LAST_VIEW/PENDING_ROLE_STATE | 在线玩家服务状态 | JOIN 初始化、旁观变化/状态同步 | 退服清；恢复自己视角回推 | 按视角/同步语义 | 清空 |
| 配置编辑上下文 | 客户端菜单/单次提交 | 进入编辑、提交期间 | 断开主线程收尾 | 不以局终删除已保存配置 | finally/removed/连接收尾 |

## 线程读写归属

| 对象/操作 | 写入线程 | 读取者 | 同步/发布方式 |
| --- | --- | --- | --- |
| 世界、实体、SRE CCA、位置与当前角色 | Minecraft 服务端 | 服务端逻辑 | 原生开局/阶段迁移校验 server thread |
| 语音权限参与者/角色/组/距离视图 | 服务端 tick | SVC UDP 音频线程 | volatile 发布、Map.copyOf/List.copyOf；记录不持有世界或玩家 |
| SVC 原生组信息 | Voicechat API | 音频处理 | 只通过音频连接 API 读取；core 组优先 |
| 场景 section 捕获与区块票 | 服务端 tick | 捕获服务 | 后台任务只拿捕获数据；取消及票释放在服务端 |
| 场景压缩、分片文件读取 | 捕获/传输后台线程 | 后台计算 | 固定源文件、不可变输入；完成跳回 server.execute 后复验 |
| 场景暂存/正式发布 | 单后台发布任务 | 服务端确认/停服 | 服务监视器与世代/编辑器身份；取消后有限等待 |
| 客户端纹理、地图/角色镜像 | 客户端主/渲染线程 | 渲染与 UI | INIT/JOIN/DISCONNECT 顺序、具体连接校验 |
| 角色扩展配置 | 配置加载/命令 | 服务端快照构造 | synchronized 更新；复制 section 后 volatile 发布 |
| RoleSpi 单例槽 | 装配与首次解析 | 公开 API | 同步解析、volatile 实例、构造重入检测 |
| NBT 原始槽与额外字段 | 拥有者 CCA 读写路径 | 状态服务 | 未识别 Tag 复制保留；有意移除的已识别槽不复活 |

有限等待超时后会记录告警，结果依靠世代和身份检查拒绝回写；没有把超时谎报为后台线程已经退出。尚需实际停机验收证明各锁顺序和线程退出行为。
