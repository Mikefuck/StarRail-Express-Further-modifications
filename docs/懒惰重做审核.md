# 懒惰重做审核

## 2026-09-08 修复

- 技能与头像选择统一校验正在对局、施法者存活、角色为懒惰且未被沉睡。
- 服务端阻止沉睡者主动起床和使用统一角色技能；破盾时先解除沉睡标记，再起床并调用上游大嗓门能力。
- 清理非对局状态下的任务标记、累计次数与沉睡状态，避免跨局残留。
- 沉睡开始时关闭容器、终止物品使用，并使用原版躺下后的坐标作为固定位置。
- 黑屏在最终画面渲染阶段补绘，隐藏 HUD 后仍有效；暂停菜单和开局、结算转场保留可用。
- 自定义胜利按明确的获胜玩家名单判定，不再因场上有存活懒惰而蹭到其他角色的胜利。
- 停电模式只结算实际达成条件的懒惰玩家，并避免重复调用 SRE 与停电结算。
- 忽略离开背包后才收到的头像列表，按窗口高度调整列表行数。

## 游戏内验收

构建和单元测试不能替代多人运行验证。需使用同时安装更新版本的客户端与服务器检查：

1. 5 格内外边界、30 秒冷却，以及下一次真实睡觉任务分配。
2. 完成两次睡觉任务后出现头像；死亡玩家和被沉睡的懒惰不能发包施法。
3. 原地躺下、其他客户端看到睡姿；F1、背包、技能键和主动起床不能解除沉睡。
4. 破盾只触发一次醒来和大嗓门能力；原有护盾叠加及限时护盾到期也需覆盖。
5. 同时三人沉睡后懒惰躺床获胜；两人沉睡、自己被强制沉睡、其他角色获胜时不得误判。
6. 对局结束后正常起床，下一局任务次数与强制任务标记归零。
